# Student OS v2 Product Scope

## Core promise

Give schools one reliable place to run everyday student operations instead of stitching together spreadsheets, paper records and group chats.

## MVP

### Admin
- Sign in
- Create/manage classes and sections
- Add teachers
- Enroll students
- View school-wide attendance

### Teacher
- Sign in
- See assigned classes
- Open a class roster
- Mark attendance
- Correct attendance for an authorized date

### Student
- Sign in
- See profile and class
- See personal attendance history

## Explicitly out of MVP

Messaging, exams, report cards, analytics, QR attendance, AI assistant, payments, parent accounts and multilingual UI will be added only after the core attendance workflow is stable.

## Definition of done for MVP

A fresh school can be created, an admin can configure one class, teacher and students, the teacher can record attendance, and a student can see the correct attendance without exposing data from another school.
